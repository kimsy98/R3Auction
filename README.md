# R3Auction-user-service
- **프로젝트 기간 :** 2024.11. ~ 2025.01.
- **인원 :** FE 1 명, BE 2 명
- **서비스 개요**
    - 사용자 간 중고 가구 경매 및 입찰을 실시간으로 중개하는 서비스

### **Spring Batch 파티셔닝을 통한 배치 성능 개선(** **33.5s → 6.8s로 79.7% 향상)**

- **상황**: 사용자 매너온도를 일정 주기로 계산하여 업데이트하는 기능이 필요했습니다.
- **문제**: 초기에는 단일 스레드로 처리되어 전체 배치 시간이 과도하게 소요되었습니다.
- **행동**: Spring Batch에 병렬 처리 설정(멀티스레드, 파티셔닝 등)을 적용하여 성능을 개선했습니다.
- **결과**: 배치 처리 시간이 크게 단축되어 운영 효율성과 사용자 데이터 반영 속도가 향상되었습니다.(싱글 스레드 → 파티셔닝 방식으로 변경하므로써 **33.5s → 6.8s 로 성능 향상(79.7% 향상)**)

---

### **카카오 페이 API 연동 및 포인트 충전**

- **상황**: 경매에서 물건을 구매할 때 사용할 수 있는 포인트 충전 기능이 필요했습니다.
- **행동**: 카카오 페이 API를 연동하여 안전하고 편리한 충전 시스템을 구현했습니다.
- **결과**: 외부 결제 수단을 통한 포인트 충전 기능을 완성하여 실제 결제 흐름을 도입할 수 있었습니다.

---

### OAuth 2.0 기반 인증 시스템 구축(KaKao)

- **상황**: 신규 유저 진입 장벽을 낮추기 위해 간편한 로그인 수단이 요구되었습니다.
- **행동**: OAuth2.0 기반의 카카오 소셜 로그인 기능을 구현하여 인증 과정을 간소화했습니다.
- **결과**: 회원가입/로그인 과정을 단순화하여 진입 장벽을 낮췄습니다.
